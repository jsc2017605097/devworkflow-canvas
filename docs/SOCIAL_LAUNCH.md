# Social launch checklist (GitHub trending)

Trending is driven by **stars in a short window** + **visibility**. Use this after the repo is polished.

## Before you post

- [ ] Record `docs/demo.gif` (see [RECORD_DEMO.md](RECORD_DEMO.md))
- [ ] Set GitHub repo **About** description + website (if deployed)
- [ ] Add topics on GitHub (see README / repo settings)
- [ ] Pin the repository on your profile

## Where to share (pick 3–5)

| Platform | Tip |
|----------|-----|
| **X (Twitter)** | Short clip + link + hashtags `#opensource #react #gemini #systemdesign` |
| **Reddit** | r/reactjs, r/webdev, r/selfhosted — follow each sub’s rules |
| **Hacker News** | "Show HN: DevWorkflow Canvas – AI system diagrams from text" |
| **Dev.to / Hashnode** | Tutorial post: "From prompt to architecture diagram in 30 seconds" |
| **LinkedIn** | Vietnamese + English post for local dev community |
| **Facebook groups** | VN dev groups (React, Backend) — focus on demo GIF |

## Timing

- Post **Tuesday–Thursday**, morning US time (evening VN) for global reach
- Reply to every comment in the first 24h
- Ask 5–10 friends to star **on launch day** (organic network matters)

## Deploy demo (optional, high impact)

Hosting a live demo (Vercel/Railway) with your API key on the server increases conversion — add URL to repo About section.
